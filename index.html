Learning journey

Building the isolated lab

The first lab taught me that safe testing starts with network design, not tools. I put Kali Linux and Metasploitable 2 on a VirtualBox Host-Only network (192.168.56.0/24) and deliberately avoided Bridged mode, so a deliberately vulnerable machine could never be reached from the physical network. I verified the set-up with ip a, ping tests and the adapter settings instead of assuming it worked. This connected directly to the authorisation and ethics material: I only test systems I own or control, and I now treat scope and permission as the first step of any test.

Nmap service enumeration

Host discovery (-sn) followed by version detection (-sV) showed me how much an attacker can learn from banners alone: one host exposed 23 open ports and many outdated services. The most useful lesson was that a version string is a lead, not proof. vsftpd 2.3.4 is linked to CVE-2011-2523, but only a tampered copy distributed for a few days in July 2011 contained the backdoor. I learned to word findings carefully and to verify before claiming a vulnerability exists.

What went wrong

In my first write-up I reported three active hosts, but the Nmap output listed four, and I claimed Kali did not appear in the results. I diagnosed this by comparing every address in the scan with the output of ip a on both VMs and with the host adapter settings. 192.168.56.106 was my own Kali machine, which Nmap lists without a MAC address or latency because it is the scanner. I corrected the write-up, and I now reconcile every scan result with a known device before describing it. Earlier in the lab I also typed ipconfig on Metasploitable and got “command not found”, because it is a Linux system. Switching to ip a fixed it.

What I still find challenging

Cloud IAM, especially writing least-privilege policies. I have seen IAM from the operations side in my team, but turning “only what the job needs” into precise AWS policy statements, and checking them against CloudTrail logs, is new to me. The Capital One breach case study showed how costly broad permissions can be.
